# Tutor Übungen

Dieser Ordner enthält Übungen, die im Rahmen des Tutors durchgeführt wurden. Enthalten:

- **Übungen**: `uebung_1/`, `uebung_1_ts/`, `uebung_2/`, etc.

### Gelehrte Inhalte:
- **Übung 1**:
  - Grundlagen von HTML und CSS in Kombination mit React.
  - Aufbau einer einfachen React-Komponente.
- **Übung 1 (TypeScript)**:
  - Einführung in TypeScript mit React.
  - Typisierung von Props und State.
- **Weitere Übungen**:
  - State-Management: Verwendung von `useState` und `useReducer`.
  - Hooks: `useEffect`, `useContext`.
  - Routing: Navigation mit React Router.
  - Testing: Grundlegende Tests mit Jest.

Verwendung: Sammlung von Übungsaufgaben für verschiedene Themen.
